* Do NOT break any existing functionality.

# 1. Automatic Delhivery Shipment Creation

Currently Delhivery is integrated.

Improve it so that:

* After Razorpay payment verification succeeds
* OR after a COD order is confirmed (if COD is enabled)

the system should automatically:

1. Create shipment on Delhivery.
2. Generate AWB/Waybill.
3. Save all shipment information in database.

Store:

* shipment_id
* waybill
* courier_name
* courier_status
* tracking_url
* pickup_location
* expected_delivery_date
* created_at

If shipment creation fails:

* Order should still be saved.
* Admin should receive notification.
* Error should be logged.
* Shipment can be retried later.

Never lose an order because shipment creation failed.
