A critical bug exists in the Product Update API.

Current error:

PATCH /api/products/{id}

returns

HTTP 500 Internal Server Error

with

Content-Length: 0

The frontend then throws

Failed to execute 'json' on 'Response': Unexpected end of JSON input

Your task is to debug and permanently fix this issue.

* api/products PATCH route
* Router configuration
* ProductController update method
* ProductModel update method
* Database queries
* Validation
* Uploaded images
* JSON decoding
* Request body parsing
* PHP exceptions
* PDO exceptions
* Transactions

Log every exception.

Never allow a blank response.

### API Response Standard

Every API endpoint must ALWAYS return JSON.

Success:

```json
{
    "success": true,
    "message": "Product updated successfully",
    "data": {}
}
```

Failure:

```json
{
    "success": false,
    "message": "Actual error message",
    "error": "...",
    "line": 123,
    "file": "ProductController.php"
}
```

Never return an empty body.

Compare ProductModel with actual MySQL table.

### Frontend

Update apiFetch() so it safely handles empty responses.

Replace

```javascript
const data = await response.json();
```

with

```javascript
const text = await response.text();

const data = text ? JSON.parse(text) : {};

if (!response.ok) {
    throw new Error(data.message || "Server Error");
}
```

This prevents "Unexpected end of JSON input".
